# Customer Churn Prediction

## Project Overview
This project analyzes customer data to understand customer churn and predict whether a customer may leave a service.

## Objectives
- Analyze customer churn patterns.
- Explore customer behavior and service usage.
- Identify important factors associated with churn.
- Predict possible customer churn using Machine Learning.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Streamlit

## Machine Learning
A Random Forest Classifier is trained using a preprocessing pipeline that handles numerical and categorical features.

## Model Performance
- Accuracy: 77.36%
- Test records: 1,409

## Dashboard Features
- Customer churn KPIs
- Interactive filters
- Customer insights and visualizations
- Customer churn prediction form

## How to Run
1. Install the required Python packages.
2. Run `python main.py` to train the model.
3. Run `streamlit run app.py` to launch the dashboard.

## Disclaimer
Predictions are estimates based on historical data and are not guarantees of future customer behavior.
